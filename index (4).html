About

Curious about the "why" behind every number

I enjoy taking large, messy datasets and making them make sense. My favourite moment in any project is when a pattern jumps out of the data and suddenly the business question has a clear answer.

I focus on data cleaning, exploratory analysis, KPI reporting and dashboard design. I care as much about how a finding is communicated as about the analysis itself, because insight only matters if someone can act on it.

I'm a Computer Science graduate from JNTUH (First Class with Distinction), which gave me a solid technical base in programming and databases. I'm now building on it with a Data Analytics course in Adelaide, adding new projects here as I go.
